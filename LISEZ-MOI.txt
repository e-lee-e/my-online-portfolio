=============

ci-dessous. Les noms sont sans accent ni espace, pour éviter les
problèmes d'encodage dans les URL sur GitHub Pages.

Deux points à vérifier avant de publier
---------------------------------------

1. Le poids total tourne autour de 20 Mo. GitHub Pages l'accepte, mais le
   dépôt grossit vite si tu remplaces souvent les fichiers. Si tu veux
   alléger, compresse les PDF avant de les déposer.

2. Le rapport FinSecure contient les coordonnées de ton binôme et des
   numéros de téléphone sur la page de garde. Vérifie qu'il est d'accord
   pour une publication en ligne, ou publie une version avec cette page
   caviardée.
