Les rapports

Six machines pour lesquelles j'ai rédigé un write-up. Chaque page commence par un résumé de la chaîne d'attaque, pour que la lecture reste utile même sans avoir fait la machine, puis reprend les étapes clés de ma résolution sans détailler chaque commande.

  • Linux
  • Facile
  • Machine retirée

Cap

Trois services exposés, FTP, SSH et un serveur web d'administration, puis une capability linux posée sur un binaire, qui suffit à devenir root

  • Linux
  • Starting Point, Tier 2

Unified

Un portail UniFi Network exposé derrière un proxy HTTP, puis le panneau d'administration livre ensuite un mot de passe ssh

  • Linux
  • Facile
  • Machine retirée

TwoMillion

Un JavaScript obfusqué côté client, qui cache la logique de génération du code d'invitation, puis un fichier .env avec des identifiants réutilisés, puis un noyau obsolète et cve-2023-0386

  • Windows
  • Facile
  • Machine retirée

Support

Un partage SMB accessible sans authentification, puis une relation d'objets révélée par bloodhound, puis une délégation contrainte basée sur les ressources

  • Linux
  • Très facile
  • Machine retirée

Orion

Un domaine à résoudre localement avant de pouvoir atteindre le site, puis une version vulnérable de telnetd, cve-2026-24061, qui permet un contournement d'authentification

  • Linux
  • Facile
  • Machine retirée

Nexus

Un service Gitea exposé, dont un dépôt laisse fuiter des identifiants, puis un service de synchronisation de templates vulnérable au path traversal, qui mène à root

Le lien avec les cours

Ces machines ne sont pas un loisir séparé du reste. Cap repose sur une capability Linux mal posée, exactement le sujet de l'atelier d'élévation de privilèges. Support se termine sur une attribution de droits trop large dans Active Directory, ce que le modèle AGDLP vu en TP existe précisément pour éviter. Orion et TwoMillion tournent autour d'identifiants réutilisés et d'API mal protégées, les deux failles que j'ai documentées dans l'audit FinSecure. La différence tient au format : le TP explique une méthode, le write-up raconte une résolution, fausses pistes comprises.
